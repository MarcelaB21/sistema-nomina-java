# Laboratorio de Ejercicios: Sistema de Nómina

Este proyecto contiene una serie de retos y ejercicios prácticos en Java para dominar la lógica de backend, el uso de colecciones y la programación funcional.

## 📝 Ejercicios Resueltos

* **Reto 1 (POO):** Creación de jerarquías de empleados (`Empleado`, `Gerente`) con cálculo de salarios.
* **Reto 2 (Excepciones):** Validación de datos con una excepción personalizada (`SalarioInvalidoException`).
* **Reto 3 (Lambdas & Consumer):** Implementación de un método genérico `procesarAccion` usando la interfaz funcional `Consumer`.
* **Reto 4 (Streams API):** Filtrado y conteo de empleados en modalidad remota.
* **Reto 5 (Reporte Avanzado):** Promedio de salarios con `mapToDouble`, manejo de strings con `Collectors.joining` y búsqueda segura con `Optional` (`max`, `orElse`).

## 🛠️ Tecnologías
* Java 17+
* Maven
* IDE: Apache NetBeans
